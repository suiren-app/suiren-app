How to accept

  1. Install Suiren from the App Store, if you haven't yet.
  2. Come back to this page and tap Open in Suiren, or type the code in Settings → Friends → I was invited.
  3. Accept once your first koi has hatched. Your friend's storey appears the next time they open Suiren. Each pond can accept one invite.

Invites use iCloud. Suiren saves only the code, a colour and an anonymous iCloud ID, never your name or contacts. See the Privacy Policy.
